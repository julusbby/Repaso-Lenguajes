# PHP Práctica — Guía rápida de repaso

Carpeta de archivos `.php` organizados por tema, numerados del 1 al 12.
Cada archivo tiene código comentado en español (para leer y recordar rápido)
y termina con una **sección de ejercicios** para practicar.

## Contenido

| # | Archivo | Tema |
|---|---------|------|
| 1 | `1-hello.php` | Introducción a PHP, etiquetas, echo/print, comentarios |
| 2 | `2-variables.php` | Variables, concatenación, constantes, scope |
| 3 | `3-tipos-de-datos.php` | int, float, string, bool, array, null, casting |
| 4 | `4-operadores.php` | Aritméticos, asignación, comparación, lógicos, ternario |
| 5 | `5-condicionales.php` | if / elseif / else, switch, match |
| 6 | `6-bucles.php` | for, while, do-while, foreach, break/continue |
| 7 | `7-arrays.php` | Arrays indexados y funciones comunes de arrays |
| 8 | `8-arrays-asociativos.php` | Arrays con claves, arrays multidimensionales |
| 9 | `9-funciones.php` | Funciones, parámetros, retorno, closures, arrow functions |
| 10 | `10-strings.php` | Funciones para manipular texto (cadenas) |
| 11 | `11-poo-basico.php` | Clases, objetos, constructor, visibilidad, static |
| 12 | `12-poo-herencia.php` | Herencia, clases abstractas, interfaces |

## Cómo ejecutar

Con PHP instalado (o desde XAMPP con PHP en el PATH), en la terminal:

```bash
php 1-hello.php
```

O abre la carpeta completa en VS Code (recomendado: extensión **PHP Intelephense**
o **PHP Debug**) y ejecuta cada archivo desde la terminal integrada.

## Cómo usar esta carpeta para repasar

1. Lee los comentarios de cada archivo de arriba hacia abajo, son explicaciones cortas.
2. Ejecuta el archivo para ver el resultado real en pantalla.
3. Ve a la sección `SECCIÓN DE EJERCICIOS` al final y resuélvelos sin mirar el ejemplo.
4. Si te trabas, sube de nuevo al código de ejemplo del mismo archivo.
